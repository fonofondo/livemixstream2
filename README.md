# AsaphOps

This repository’s product is **AsaphOps** in [`asaphops/`](asaphops/README.md): ops web app, companion, and DAW plugin.

```bash
cd asaphops
npm install
npm start
```

Open http://localhost:3100 — demo login `ops@asaphops.local` / `asaphops`.

Push to `main` to build the macOS companion (`.app`) plus VST3 and AU. In GitHub: **Actions → AsaphOps macOS** → download **AsaphOps-macOS**.
